# Sports Quiz

A quiz web app with separate quizzes for **football, basketball, badminton and cricket**.

**Live demo:** https://abhinibesh-fresher.github.io/sports-quiz/

## Features
- 4 separate sports quizzes with multiple-choice questions
- Timer for each question
- Instant feedback: green for correct, red for wrong
- Motivational notes after wrong answers (different every time)
- Leaderboard with a top list for each sport
- Scores saved in the browser using localStorage
- Works on mobile and desktop

## Built with
- HTML
- CSS
- JavaScript

## How to run
1. Download or clone this repository
2. Open `index.html` in any browser
